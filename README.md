# Smart Attendance Management System

## Overview
Smart Attendance Management System is a web-based application developed using Java Server Pages (JSP) that automates student attendance management within educational institutions. The system enables administrators, faculty members, and students to efficiently manage and monitor attendance records in real time.

The application eliminates manual attendance tracking, improves accuracy, reduces paperwork, and provides quick access to attendance reports.

---

## Features

### Admin Module
- Admin Login Authentication
- Manage Student Records
- Manage Faculty Records
- View Attendance Information
- Generate Attendance Reports

### Faculty Module
- Faculty Login
- Mark Student Attendance
- View Student Attendance Details
- Generate Monthly Attendance Reports
- Update Attendance Records
- Manage Working Days Information

### Student Module
- Student Login

- Access Attendance Reports

### Additional Features

- Attendance Percentage Calculation

- Feedback Management

## Installation Steps

### Prerequisites
- Java JDK 8 or above
- Apache Tomcat Server
- MySQL Server
- JDBC MySQL Connector
- Eclipse IDE / NetBeans

### Setup

1. Install Java JDK.
2. Install Apache Tomcat Server.
3. Install MySQL Database.
4. Import the database script into MySQL.
5. Import the project into Eclipse/NetBeans.
6. Configure database connection settings.
7. Add MySQL JDBC Connector to the project libraries.
8. Deploy the project on Apache Tomcat.
9. Start the server.
10. Open the application in a browser.

```
http://localhost:8080/SmartAttendanceSystem
```
